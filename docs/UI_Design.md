# 화면 설계서 (UI/UX Design Document)

이 문서는 **타로2026** 프로젝트의 화면 구성, 사용자 인터랙션, 그리고 시각적 상세를 정의합니다.

## 1. 공통 레이아웃 (Common Layout)
모든 페이지에 공통적으로 적용되는 사항입니다.

*   **배경 (Background)**
    *   Deep Violet (#2E004F) 기반의 그라디언트.
    *   은은하게 반짝이는 별 파티클 효과 (Particle JS 활용).
*   **헤더 (Header)**
    *   좌측 상단: 로고 'Tarot 2026' (클릭 시 홈으로 이동).
    *   우측 상단: 배경음악 Toggle 버튼 (Speaker Icon).
*   **푸터 (Footer)**
    *   저작권 표기 및 간략한 정보 (하단 고정 아님, 콘텐츠 아래 위치).

## 2. 페이지별 상세 설계

### 2.1 인트로 페이지 (Intro Page)
사용자가 처음 마주하는 랜딩 페이지입니다.

*   **레이아웃**: 중앙 정렬 (Flex Center).
*   **주요 요소**:
    *   **메인 타이틀**: "2026년 당신의 운세" (Typography Animation).
    *   **보조 텍스트**: "신비로운 타로 카드가 들려주는 당신의 미래"
    *   **메인 이미지/오브젝트**: 공중에 떠있는 타로 카드 한 장 (Breathing Animation).
    *   **CTA 버튼**: [ 운세 보러가기 ] (Gold Gradient, 호버 시 빛나는 효과).
*   **인터랙션**:
    *   접속 시 타이틀이 페이드인 되며 나타남.
    *   버튼 클릭 시 화면이 전환되며 카드 셔플 사운드 재생.

### 2.2 카드 선택 페이지 (Card Selection Page)
사용자가 운세를 점칠 카드를 직접 뽐는 화면입니다.

*   **레이아웃**: 상단에 안내 문구, 중앙에 카드 덱.
*   **화면 시나리오**:
    1.  **진입**: 카드 덱이 촤르륵 펼쳐지며 뒷면을 보여줌 (Fan shape 또는 Grid).
    2.  **셔플**: "카드를 섞고 있습니다..." 문구와 함께 카드가 섞이는 애니메이션.
    3.  **대기**: "당신의 2026년을 생각하며 3장을 선택하세요." 문구 표시.
*   **주요 요소**:
    *   **카드 덱**: 뒷면 디자인의 카드 22장.
    *   **진행 상태바 (Progress Bar)**: 선택한 카드 수 표시 (ex: 1/3).
*   **인터랙션**:
    *   **Hover**: 마우스 오버 시 카드가 살짝 위로 올라옴 (모바일은 터치 시 반응).
    *   **Click/Touch**: 카드가 선택되어 별도의 슬롯(화면 하단)으로 이동.
    *   3장 선택 완료 시 자동으로 결과 로딩 화면으로 전환.

### 2.3 결과 페이지 (Result Page)
선택한 카드의 의미를 해석해주는 핵심 화면입니다.

*   **레이아웃**: 스크롤 가능한 세로형 레이아웃.
*   **구성 요소**:
    *   **섹션 1 (과거/현재/미래 or 총운/연애/금전)**: 선택한 카드 3장이 뒤집힌 상태로 배치.
    *   **카드 오픈**: 순차적으로, 또는 탭하여 카드를 뒤집음.
    *   **상세 해석**: 각 카드 하단에 [카드 이름], [키워드], [상세 해석 텍스트] 표시.
    *   **하단 액션바**:
        *   [ 다시하기 ] 버튼.
        *   [ 공유하기 ] 버튼 (이미지 저장, 링크 공유).
*   **시각 효과**:
    *   카드 뒤집힐 때 빛나는 효과 (Glow Effect).
    *   중요 키워드는 **Bold** 및 **Color** 처리로 강조.

## 3. 디자인 시스템 (Design System Keywords)

*   **Colors**:
    *   Background: `#2E004F` ~ `#140024` (Linear Gradient)
    *   Primary Text: `#FFFFFF` (White)
    *   Accent: `#FFD700` (Gold), `#00FFFF` (Neon Blue)
*   **Typography**:
    *   Title: 'Cinzel', 'Gowun Batang' (명조 계열, 신비로움)
    *   Body: 'Pretendard', 'Noto Sans KR' (고딕 계열, 가독성)
*   **Iconography**:
    *   Line 스타일의 얇고 세련된 아이콘 (Lucide React 권장).

## 4. 모바일 고려사항 (Responsive)
*   카드 선택 시 손가락 터치 영역을 충분히 확보 (최소 44x44px).
*   PC에서는 카드를 부채꼴로 펼치더라도, 모바일에서는 가로 스크롤 또는 Grid 형태로 배치하여 공간 효율화.
