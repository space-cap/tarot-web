# 2026년 신년 타로 운세 프로젝트 기획서 (PRD)

## 1. 프로젝트 개요 (Project Overview)
**프로젝트명**: 타로2026 (Tarot 2026)  
**목적**: 사용자가 2026년의 운세를 타로 카드를 통해 재미있게 확인하고, 긍정적인 메시지를 얻을 수 있는 반응형 웹 서비스 구축.  
**타겟 유저**: 모바일 기기에 익숙하고 신년 운세나 타로/점성술에 관심이 많은 사용자.

## 2. 사용자 시나리오 (User Scenario)
1.  **접속**: 사용자가 웹사이트에 접속합니다.
2.  **인트로**: 2026년의 신비로운 분위기를 담은 인트로 화면을 마주하고 '점 보러 가기' 버튼을 클릭합니다.
3.  **집중 및 셔플**: 사용자가 집중할 수 있도록 유도하는 문구와 함께 뒷면의 카드들이 셔플되는 애니메이션이 재생됩니다.
4.  **카드 선택**: 사용자가 직접 카드 3장(또는 1장)을 터치하여 선택합니다.
5.  **결과 확인**: 선택한 카드가 뒤집히며 화려한 효과와 함께 결과(카드 이미지, 이름, 해석)가 나타납니다.
6.  **공유하기**: 결과를 이미지로 저장하거나 SNS(카카오톡, X, 인스타그램 등)에 공유합니다.

## 3. 핵심 기능 (Key Features)

### 3.1 메인 페이지 (Landing)
*   프로젝트 타이틀 및 로고 배치
*   "2026년 당신의 운명은?" 등의 흥미 유발 문구
*   배경 음악 ON/OFF 기능 (선택사항)
*   **Action**: '시작하기' 버튼

### 3.2 카드 셔플 및 선택 (Selection)
*   **덱 구성**: 메이저 아르카나 22장 (또는 전체 78장)
*   **애니메이션**: 부드러운 카드 셔플 및 펼침 효과 (CSS/JS Animation)
*   **인터랙션**: 호버 효과, 클릭 시 카드 선택 이펙트

### 3.3 결과 페이지 (Result)
*   **카드 디스플레이**: 고해상도 타로 카드 이미지
*   **AI 해석 (Interpretation)**:
    *   선택된 카드를 기반으로 2026년 총운, 연애운, 금전운 등 해석 제공
    *   (옵션) Gemini API 등을 활용하여 실시간 생성 또는 사전 정의된 데이터베이스 사용
*   **공유 기능**: 결과 URL 복사 또는 소셜 미디어 공유 버튼

## 4. 기술 스택 (Tech Stack)
*   **Frontend**: React v19, Vite
*   **Language**: JavaScript (ES6+) / TypeScript (권장)
*   **Styling**: CSS Modules 또는 Vanilla CSS (반응형 디자인 필수)
*   **Deployment**: Vercel, Netlify, or Github Pages
*   **Assets**: 생성형 AI(Midjourney/Flux/Gemini)로 제작된 타로 카드 이미지 리소스

## 5. 디자인 가이드 (Design Guidelines)
*   **테마 컬러**:
    *   Primary: Deep Violet (#2E004F) - 신비로움
    *   Secondary: Gold (#FFD700) - 희망, 부
    *   Accent: Electric Blue (#00FFFF) - 미래지향적 에너지
*   **폰트**: 가독성이 좋으면서도 신비로운 느낌의 Serif (제목) + Sans-serif (본문) 조합

## 6. 개발 일정 (Timeline)
*   **1단계 (기획/준비)**: PRD 작성, 에셋 준비 (완료)
*   **2단계 (개발)**: 프로젝트 세팅, 컴포넌트 개발 (Index, Card, Result)
*   **3단계 (연동/기능)**: 카드 로직 구현, 결과 해석 데이터 연동
*   **4단계 (배포/테스트)**: 버그 수정 및 최종 배포

## 7. 폴더 구조 (예시)
```text
/src
  /assets
    /cards       # 타로 카드 이미지
  /components
    /Intro       # 시작 화면
    /Deck        # 카드 덱 및 셔플 영역
    /Card        # 개별 카드 컴포넌트
    /Result      # 결과 화면
  /data          # 타로 카드 의미 데이터 (JSON)
  /hooks         # 커스텀 훅 (카드 선택 로직 등)
  /styles        # 공통 스타일
  App.jsx
  main.jsx
```
