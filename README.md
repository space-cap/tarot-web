# Tarot 2026 (타로2026) - AI Powered Destiny Reader

AI 기반의 인터랙티브 타로 운세 웹 애플리케이션입니다. React와 OpenAI API를 활용하여 사용자에게 신비롭고 개인화된 타로 리딩 경험을 제공합니다.

## ✨ 주요 기능 (Key Features)

### 1. 직관적인 타로 리딩 (Interactive Reading)
- **셔플 & 선택**: 실제 카드를 섞고 뽑는 듯한 비주얼 효과.
- **3카드 스프레드**: 과거/현재/미래(또는 상황/조언/결과) 기반의 상세 리딩.

### 2. AI 오라클 (AI Oracle - Grand Master)
- **심층 해석**: OpenAI GPT 모델을 활용한 "Grand Master" 페르소나의 장문 에세이 리딩.
- **운세 스코어**: 금전, 애정, 건강, 학업/사업운을 점수화하여 그래프로 제공.
- **투명성**: 사용된 프롬프트와 원본 응답을 확인할 수 있는 디버깅 모드 지원.

### 3. 신비의 서 (Book of Mystery)
- **타로 가이드**: 타로의 역사, 구조, 리딩 방법을 배울 수 있는 교육 섹션.
- **Elegant UI**: 몰입감을 주는 다크 테마와 부드러운 애니메이션.

## 🛠 기술 스택 (Tech Stack)
- **Frontend**: React, Vite
- **Styling**: CSS Modules, Framer Motion (Animation)
- **AI**: OpenAI API (gpt-3.5-turbo)
- **Icons**: Lucide React
